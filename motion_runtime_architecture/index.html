核心优势

架构的价值不是类更多，而是替换成本更低

01

算法可换

Planner 在构造时绑定准确 IK；解析、多种子或后续新实现可以同时注册，由配置选择，不改任务主流程。

02

环境可换

Direct/ROS2 只改变 Communication，Fake/Twin/Real 只改变 Runtime Adapter，MotionEngine 保持不变。

03

测试可控

ManualClock、脚本化 Fake 和固定 Snapshot 让失败、超时、取消、重试与幂等无需真机即可确定性复现。

04

问题可追

每次调用统一记录 Job、Snapshot、Stage、Node、Object、Operation、Attempt、Duration 和稳定错误码。
