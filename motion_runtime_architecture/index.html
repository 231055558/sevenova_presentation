robot_motion_control 目标运行时架构

目标架构 v1 · 统一对象系统

一个 MotionSystem，启动构建对象图，任务只运行任务图。

目标不是再造一批 ROS 包，而是形成一个可直接调用、可接 ROS、可组合算法、可替换真机与数字孪生、 能审计完整执行过程的运控程序。URDF、MoveIt、ROS 和孪生都在对象系统中拥有明确位置。

启动失败即关闭入口 类型安全对象图 有界并发 主站实时插值 Direct/ROS2 可切换
阅读这份文档时请区分

`docs/system_flow` 描述当前仓库；本门户描述目标架构 v1。ObjectGraph 是启动实例关系， TaskGraph 是任务流程；C++ 目录、ROS package 和运行进程都不能代替这两个概念。
