已确认的 6 条硬规则

一一映射每个最小状态对应一个标准 stage_result.stage。
双名制state_id 给状态图看，stage 给日志和接口用。
状态边界改变系统理解的世界状态，就拆独立状态。
双臂结果主流程任务级，执行结果 left/right slot 级。
异常矩阵失败必须写清 failure_status → recovery_action → next_state。
场景门槛箱子归属/位置变化必须更新 MoveIt scene。
